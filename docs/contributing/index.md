# Contributing to Takwin

Thank you for your interest in contributing to Takwin! This guide will help you get started.

## Ways to Contribute

There are many ways to contribute to Takwin:

- 🐛 **Report bugs** - Help us identify and fix issues
- 💡 **Suggest features** - Share your ideas for improvements
- 📝 **Improve documentation** - Help others understand Takwin
- 🔧 **Submit code** - Fix bugs or implement features
- 🧪 **Write tests** - Improve code coverage and reliability
- 💬 **Help others** - Answer questions in Discussions

## Code of Conduct

We are committed to providing a welcoming and inclusive environment. Please:

- Be respectful and considerate
- Welcome newcomers and help them learn
- Focus on what is best for the community
- Show empathy towards other community members

## Getting Help

If you need help contributing:

- 💬 Ask in [GitHub Discussions](https://github.com/hakkim/takwin/discussions)
- 📖 Read the [full contributing guide](getting-started.md)
- 🐛 Check existing [issues](https://github.com/hakkim/takwin/issues)

## Recognition

Contributors are recognized in:

- GitHub contributors list
- Release notes
- Project README

Thank you for making Takwin better! 🎉
